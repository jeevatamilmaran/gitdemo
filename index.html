Git vs GitHub

A visual breakdown of version control and remote collaboration

1. The Core Difference

What is Git?

Git is a tool (Software). It runs locally on your computer to track changes in your code, record history, and allow you to switch between different versions of your project.

What is GitHub?

GitHub is a service (Cloud Platform). It is a website where you upload, host, and share your Git repositories online so teams can collaborate from anywhere.

2. How Local Changes Flow to the Cloud

Before your updates appear on GitHub, your files pass through three local stages on your machine:

3. Daily Action Steps

01

Save & Check Status

Modify your file (e.g., test.txt) in your editor, save it, and check what changed using git status.

02

Stage Changes

Prepare your modified files for a snapshot by running git add test.txt (or git add . for all files).

03

Commit Snapshot

Save your staged changes to your local history with a message describing the update: git commit -m "Update test file".

04

Push to GitHub

Upload your committed changes up to the remote repository online using git push origin main.
